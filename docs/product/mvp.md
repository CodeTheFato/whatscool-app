# MVP Scope

## Objetivo

Validar o produto com 1–2 escolas reais.

---

## Funcionalidades incluídas

### Comunicação

- Criar comunicados
- Enviar para:
  - turma
  - aluno específico
- Envio via:
  - plataforma (obrigatório)
  - WhatsApp (opcional)

---

### Estrutura mínima

- CRUD alunos
- CRUD turmas
- CRUD professores

---

### Integração

- envio assíncrono via SQS
- processamento via Lambda
- integração com WhatsApp Cloud API

---

## Fora do MVP

- financeiro
- contratos
- gestão completa escolar
- relatórios avançados
- permissões complexas

---

## Estratégia

1. construir MVP funcional
2. validar com escola real
3. evoluir gestão com feedback real
